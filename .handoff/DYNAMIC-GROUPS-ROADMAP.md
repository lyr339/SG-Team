## 每阶段的完成定义（摘要，细则在各任务书末节）

- **1**：新 schema 上线；SQL 层 `createGroup … dissolveGroup / addSeats / removeSeat` 可用；`team_*` 在未入组通道返回 `not_in_group`；池 run 不再被 failover 收尾；实机脚本（3 会话建组 → 分派一个任务 → 移出 → 解散）通过。
- **2**：`TeamRunStatus` 收敛为 `running | completed`，`launchStatus` 五态与 preflight 团队分支删除；旧团队 run 创建路径删除；席位重建保留组成员关系；`CursorUsageTracker` 按组 / 按会话可读；lease 决策落地（采纳或明确否决）。
- **3**：`RunPage` 不再有模式切换；会话名册多选建组、组卡片、拖入 / 移出 / 解散、lead 切换、attention；截图矩阵与几何探针通过；删除清单中的组件与样式已移除且 knip 干净。
- **4**：Cursor 面板在无分组的工作区只见 2 个工具；有分组时按分组状态出现团队工具；每轮固定预付 tokens 从 ≈4750 降到 ≤2000（团队席）/ ≤800（独立席）；协作通知不再经 outbox 信封二次投递；`smoke:channel` / `smoke:mcp` 断言新工具面。
