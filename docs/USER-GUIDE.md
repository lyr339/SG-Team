# 使用指南

[返回首页](../README.md) · [下载最新版](https://github.com/lyr339/SG-Team/releases/latest)

## 安装与更新

正常使用安装包不需要安装 Node.js。支持的平台与 Cursor 版本见 [首页](../README.md#下载与安装)。

### macOS

下载 `ShiGuang-<版本>-mac-arm64.zip`，解压，将「拾光.app」放入「应用程序」后打开。当前不提供 Intel Mac 安装包。

安装包使用 ad-hoc 签名，未做 Apple 公证，首次打开可能遇到系统安全提示；请先确认下载来源是本仓库 Release。

### Windows

下载 `ShiGuang-Setup-<版本>.exe` 并运行，可选择安装目录。Release 中的 `.yml`、`.blockmap` 和更新清单供软件更新使用，无需手动安装。

Cursor 不要求安装在 C 盘。安装路径、文件权限或本地端口冲突仍可能影响检测和补丁操作，请以软件给出的检测结果为准。

### 更新与兼容性

已安装的用户可以在 **账号与 Cursor → 软件更新** 中检查、下载和安装更新。

软件会识别本机 Cursor 版本并选择对应适配；可在 **Cursor 维护** 中重新检测。Cursor 自动更新后，请核对版本是否仍在适配范围内，不要默认新版本一定兼容。

## 第一次使用

1. **准备 Cursor**：打开目标项目，确认当前账号和模型可以正常使用。
2. **选择工作区**：打开拾光，在顶栏核对当前 Cursor 工作区，避免把会话建到另一个项目。
3. **从一个会话开始**：进入「运行」，选择模型与参数，创建会话并按界面提示完成接入。
4. **在会话页发送任务**：查看执行过程、最终回复及右侧代码变更。
5. **需要分工时再建组**：将已有会话加入协作组，填写共同目标、分配角色；独立会话与协作组可以共存。

正常会话协作通过拾光提供的 **SG Team MCP** 接入 Cursor。保持对应 Cursor 会话可用；会话上线、进入待命和正在执行是不同状态。消息显示为排队时，不代表 Agent 已经收到。

能否发起会话取决于当前 Cursor 账号权限和模型可用性。拾光不会替代 Cursor 的登录校验，也不会增加模型额度。

## 会话、过程与协作

执行时可以查看思考、工具调用和代码差异；完成后过程收起，保留结果和手动展开入口。右栏提供变更、计划、活动与产物视图，需要接续工作时可交接上下文。

协作组通过角色、任务、消息和共享记忆组织分工。协作图展示实际消息的收发关系，不代表所有成员始终在同时执行。

通知中心保留重要结果和待处理事项，支持分类、静音与提醒偏好。**已受理、已排队不等于最终完成**，请以对应功能页的具体回执为准。

外观支持浅色、深色、六套主题色及透明度调整。左右工作区可调整宽度，按需要留出对话或审查空间。

## 账号与自动化

账号页提供本机账号管理、切换与重启入口；导入来源可配置指纹浏览器及其本地 API 端口。账号凭据在本机加密保存，不应写入日志、截图或问题反馈。

账号自动化是可选功能，不是查看会话和组织协作的前提。它可能涉及第三方处理服务、账号加固、切换或删除：启用前请核对所选服务、目标账号与「后续操作」开关。

处理结果以具体回执为准。遇到异常时先查看本轮结果，不要直接重复执行整条处理链。

## 用量与协议

统计页用于了解会话用量与产出，不能把所有本地估算直接等同于 Cursor 官方账单。

「协议」页将采集记录、模型参数和只读额度依据分开呈现，并提供实验性的 Auto / Ask 协议直连入口。直连实验与日常 MCP 协作是两条路径，不代表所有模型和原生工具都已完整支持；发送实验请求可能消耗当前账号额度。

## 清理与维护

存储清理会区分可回收内容、存在代价的内容和不可恢复的会话记录。先查看清理范围；标记需要退出 Cursor 的项目，应退出后再处理。不要把数据清理当作普通刷新。

## 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 会话已上线，但消息仍排队 | 上线不等于已进入接收消息的待命状态；查看对应 Cursor 会话与拾光中的连接提示 |
| 浏览器已登录，拾光仍无法读取 | 核对 Roxy 本地 API、端口以及账号绑定的窗口；打开任意窗口不代表选中的窗口已有登录态 |
| 升级 Cursor 后功能异常 | 到 Cursor 维护重新检测版本，确认仍在适配范围内，再按提示操作 |
| 更新拾光后，旧状态仍未恢复 | 先检查通知中心与对应功能页的具体结果，不要直接重复执行账号处理或清理 |

仍无法解决时，请提交 [Issue](https://github.com/lyr339/SG-Team/issues)，附上拾光版本、系统与架构、Cursor 版本、复现步骤、预期与实际结果。截图和日志请先遮盖 Token、密码、卡密及个人信息。
