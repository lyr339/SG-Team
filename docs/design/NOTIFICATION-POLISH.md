# 通知与结果提示的呈现约束

## 产品语言

- 结果收件箱，不做彩色日志面板。状态色只用于有语义的图标与文字；不加装饰圆点、彩色左轨或持续闪烁。
- 沿用明暗主题令牌、既有字体与数字字体；标题、正文、来源分别有明确字号层次。
- 通知不自动执行业务，不把阅读、收起说明当作修复、归档或处理完成。

## 交互与状态

- 筛选范围、计数和正文作为同一份视图提交。等待时保留原范围，不把旧列表标成新筛选；旧响应不能覆盖新范围。
- 偏好修改有即时草稿、串行保存与逐项失败回退。仅本项处于保存状态，不能把整页控件反复变灰；未发送的同项修改合并为最新意图。
- 自绘菜单使用 portal 所有权与标准 listbox 键盘操作；Esc 一次只关闭一层，返回焦点。
- 只延迟短操作的加载提示，不延迟真实请求。尊重 reduced-motion。

## 几何稳定

- 图标、正文、操作使用明确的网格或弹性列，不用固定 margin 猜对齐。
- 折叠触发器在开合时不改变 padding、margin、字号或占位宽度；仅正文参与展开和滚动。
- 长内容滚动区域预留 scrollbar-gutter；标题与动作不成为可滚动正文的一部分。
- 结果列表滚动与底栏动作分离；阅读已展开正文时，不因新推送自动替换内容。

## 完成标记

- 有明确完成证据的 Todo、过程、团队任务和自动化阶段复用 FeedbackIcon 的绿色描边圈勾。
- 文字可降级或划线，但完成图标不随整行透明度一起淡化。
- 等待、执行中、取消、跳过、待验收和未知状态各保留原语义；选择勾不使用成功颜色。
- 单一圈勾图元，不重复叠加外环或状态徽章。

## 验证

交互回归覆盖范围切换、旧响应、保存失败/重试、连续操作、存储换代、键盘与阅读回执。几何变更另做真实组件的逐帧和明暗/窄窗检查，不能以 CSS 字符串测试代替可见验收。
