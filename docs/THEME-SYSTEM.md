# 拾光主题系统

## 目标与边界

主题不是把所有颜色替换成一个色值。它统一导航选择、可操作控件、选中表面、焦点、文字选区和主操作；错误、在线状态、代码增删、文件类型、模型厂商与数据分类色不随主题改变。原有字号、布局和业务流程不是本次重构对象。

## 单一来源

- `theme-palette.ts` 定义六种低饱和主题与完整角色。旧 ID 保持有效。
- `theme-palette.generated.css` 是生成物；`npm run theme:generate` 更新它，测试核对源码与生成物，防止双份色值漂移。
- `foundation.css` 管理字体、中性内容面、状态色和结构令牌。
- `appearance-preferences.ts` 只规范化、持久化并应用属性，不再按预设写三枚不完整的覆盖值。
- `styles.css` 与页面样式只消费角色，不在组件内重算主按钮或重新指定橙色。

## 角色

| 角色 | 使用范围 |
| --- | --- |
| `--accent`, `--accent-deep` | 可操作图标、链接与选中态文字；深浅模式分别校准 |
| `--action-primary-bg/hover-bg/pressed-bg/text` | 主按钮、实心选择控件、用户气泡；前景不借用中性反色 |
| `--accent-wash/soft/selected` | 克制的强调和选中表面，保持内容可读 |
| `--accent-border*`, `--color-ring-primary` | 线与焦点，明确区分装饰线和可见焦点 |
| `--theme-selection-*` | 普通文本选区与实心主题表面内的选区 |
| `--color-background-secondary/tertiary`, `--theme-backdrop` | 工作区底层和背景图片上的轻遮罩；内容面与原生窗口按钮区域保持中性 |
| `--readable-surface` | 内容阅读面保留 78% 底色下限，原始透明度偏好与装饰背景不被重写 |
| `--action-danger-*`, `--color-control-track/thumb` | 独立语义的危险操作与关闭开关；不是主题文字色的反用 |

## 内容与交互边界

- 状态、工具类别、diff、语法、文件类型、模型参数、统计分类、品牌身份以及图像遮罩采用固定含义；它们可以一次性修正对比度，但不随用户主题漂移。
- 模型铭牌仍保留已确认的厂商身份配色，不把各家模型重新染成同一主题色。
- 主操作、账号切换入口和当前通信线条跟随主题；历史通信保留灰色角色，动态路由、流动和箭头不被移除。
- 主题动画只捕获内容区，顶栏外观控件不参与截图。快照层不拦截指针，最新意图覆盖旧回调，减少动态效果时立即更新。完整根截图会暂时禁用被截图内容的命中测试，见 [W3C View Transitions](https://www.w3.org/TR/css-view-transitions-1/#view-transition-pseudos)。
- 输入、提示和代码阅读面保留适当底色；主题选择器明确说明低透明度时的可读性下限，不再使用“完全透明”的误导文案。
- 主题选择器使用一排六枚圆形色点：24px 色点、32px 命中区，选中环与键盘焦点分开表达；名称集中在行首标签右侧，悬停提供名称和说明，左右键环绕选择。不再用多行微缩主题卡占据外观面板。

## 验收要求（缺一不可）

1. 六种主题 × 浅色、深色和系统模式均能即时切换、恢复并跨重启保存；未知/旧 ID 安全回退，无残留覆盖。
2. 有效文字/主按钮前景对比度至少 4.5:1，焦点与相邻表面对比度至少 3:1；悬停、按下、选中、禁用、保存中均检查，禁用态与可用态明确区分。
3. 会话、运行、所有设置页、通知、团队协作、过程流、代码审查和相关弹层做真实组件渲染走查，不以一块色卡代替整页验收。
4. 语义色、模型厂商色与 diff 色切换前后不变；主要安全操作跟随主题，危险操作仍保持独立语义。
5. Windows/macOS 控件布局、窄宽窗口、背景预设与透明度边界、键盘、减少动态效果和快速连续切换均覆盖。
6. 不重挂载会话，不移动滚动/焦点，不损坏输入草稿，不触发任何账号、模型或自动化操作。
7. 全量回归、类型检查、死代码检查和构建通过，生成物匹配，组件颜色旁路有明确分类和约束。

验收证据保存于工作区外的 `theme-system-review`；未满足完整页面与状态矩阵前，不将主题任务视为完成。
